# Calculator

A **light-mode GUI calculator** built using **Java Swing**, capable of performing **chained arithmetic operations** with operator precedence. The calculator supports addition, subtraction, multiplication, and division with a clean and user-friendly interface.

---

## Features
- **Chained calculations**: Supports multiple operators in a single expression (e.g., `7+2*3-1`).  
- **Operator precedence**: Multiplication and division are evaluated before addition and subtraction.  
- **Light mode UI**:
  - Clear (`C`) button → **Red**  
  - Operators (`+`, `-`, `*`, `/`) → **Yellow**  
  - Equals (`=`) → **Green**  
  - Numbers → Light gray  
- **Full expression display** while typing; pressing `=` shows the result.  
- **Backspace (`←`)** to correct mistakes.  
- **Chaining after result**: Continue calculations using the previous result.

---

## Tech Stack
- **Language:** Java  
- **GUI Framework:** Swing (AWT components)
